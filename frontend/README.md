# Frontend - Soly CRM

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- React Query
- React Router
- Supabase JS
- PWA (vite-plugin-pwa)

## Setup

1. Configurar `.env` con tus variables reales.
2. `npm install`
3. `npm run dev`

## Scripts

- `npm run dev`: modo desarrollo
- `npm run build`: build producción
- `npm run preview`: servir build
- `npm run lint`: lint
- `npm run check`: typecheck
